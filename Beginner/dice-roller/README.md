# Dice Roller

A simple command-line dice roller in Python.

## Features

- Roll 1 to 10 six-sided dice at a time
- Press Enter to roll one die by default
- Shows each die's result and the total
- Checks invalid input and lets you try again
- Roll again without restarting the program

## How to Run

1. Make sure you have Python 3 installed. No extra packages are needed.
2. From the project root, run:

   ```bash
   python Beginner/dice-roller/dice_roller.py
   ```

   Or, from this folder, run `python dice_roller.py`.

## Example

```text
Welcome to Dice Roller!
Roll up to 10 six-sided dice at a time.
How many dice? (1-10, default: 1): 2

Die 1: 3
Die 2: 5
Total: 8

Roll again? (y/n): n
Thanks for rolling!
```

Results are random, so each roll may be different. Enter `y` or `yes` to
roll again; any other response ends the program.
