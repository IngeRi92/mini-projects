# Text-Based Game

A short command-line adventure in Python where the player explores a mysterious island, makes choices, collects treasure, and tries to survive until the end.

## Features

- Explore multiple locations with different challenges
- Choose from simple text-based options
- Track health and treasure throughout the adventure
- End with a final score and custom ending message
- Includes validation for invalid menu choices

## How to Run

1. Make sure you have Python 3 installed.
2. From the project root, run:

   ```bash
   python "Beginner/text-based-game/text_based_game.py"
   ```

   Or, from this folder, run:

   ```bash
   python text_based_game.py
   ```

## Example

```text
Welcome to Moonlit Mystery!
What is your name? Mira

You arrive at the Whispering Forest. The air is thick with mist and the trees seem to hum.
Choose your next move:
1) Follow the glowing lanterns
2) Cross the old bridge
3) Search the bushes for clues

Pick a choice (1-3): 1

You follow the lanterns to a hidden clearing and recover a gold coin pouch.
Health: 3
Gold: 15

You continue to the Sunken Ruins...
```

The adventure is built around simple decisions, player input, and a few win/loss conditions. Each run can produce a different result depending on the choices you make.
